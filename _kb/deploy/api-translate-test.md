# 商业文档翻译 API 实测指引（版式优化方案③）

> 调研结论（2026-07-24）：作为"导出中文 PDF 文件"的备选通道，与 BabelDOC 0.6.4 对比实测后择优。
> 阅读场景已由「对照阅读」模式解决（原版零失真），此项仅服务导出/分享/打印需求。

## 候选（按调研推荐顺序）

| 服务 | 成本（50页） | 免费额度 | 版式口碑 |
|---|---|---|---|
| 火山引擎文档翻译 | ~¥0-6 | 每月 100 页 + 200 万字符 | 一般 |
| 阿里云文档翻译 | ~¥4（¥0.08/页） | 新户试用 | 官方称"排版高度还原"，支持图片内文字 |
| 有道智云文档翻译 | ~¥5-15 | 新户 ¥50 体验金 | 国内"样式还原"口碑最好 |

## 实测步骤

1. 注册任一家并开通文档翻译服务，取得 AK/SK
2. 把凭证加入 `_kb/.env`（如 `ALIYUN_AK=... ALIYUN_SK=...`），**告知 Claude Code 已配好哪家**
3. Claude Code 会补全 `_kb/scripts/apitrans_test.py`（上传→轮询→下载三段式），用三份既有文档实测
4. 渲染对比（已有 pdfcheck 基线图），按「目录页/大标题/导航件/字体」四个已知弱点打分择优

## 判断标准

商业 API 译版在四个已知弱点上明显优于 BabelDOC 0.6.4 → 接入为 `layout` 阶段的可选引擎（config.yaml 加 `layout_engine: babeldoc|aliyun|...`）；否则维持现状。
